# 术语索引表（Glossary）

> 知识库中常用缩写与专有名词快速索引。

| 缩写 | 全称 | 中文说明 | 所属域 |
|---|---|---|---|
| **KGR** | Keyword Golden Ratio | 关键词黄金比率：`allintitle结果数 / 月搜索量`，用于筛选低竞争高意向长尾词 | Requirements |
| **KD** | Keyword Difficulty | 关键词难度（Ahrefs/Semrush 0-100 评分） | Requirements |
| **SV** | Search Volume | 月搜索量 | Requirements |
| **SERP** | Search Engine Results Page | 搜索引擎结果页面 | Requirements / SEO |
| **pSEO** | Programmatic SEO | 程序化 SEO：通过模板+数据批量生成落地页的流量策略 | SEO |
| **GEO** | Generative Engine Optimization | 生成式引擎优化：针对 ChatGPT/Perplexity 等 AI 搜索的优化 | SEO |
| **GSC** | Google Search Console | Google 站长工具，用于监控收录与展现数据 | SEO / Operations |
| **IndexNow** | — | Bing/Yandex 的即时收录协议，替代传统 sitemap 轮询 | SEO |
| **Schema / JSON-LD** | Schema.org JSON-LD | 结构化数据标记，增强 AI 搜索与 Rich Results 提取 | SEO / Engineering |
| **ISR** | Incremental Static Regeneration | Next.js 增量静态再生成，按需更新静态页面 | Architecture |
| **SSG** | Static Site Generation | 静态站点生成，编译时预渲染页面 | Architecture |
| **MoR** | Merchant of Record | 记录商户：代理处理支付、税务、合规的第三方（如 LemonSqueezy、Paddle） | Engineering / Operations |
| **CRO** | Conversion Rate Optimization | 转化率优化 | CRO |
| **LCP** | Largest Contentful Paint | 核心 Web 指标之一，衡量首屏最大元素加载时间 | Architecture |
| **SpamBrain** | — | Google 的 AI 垃圾内容检测系统 | SEO（风控） |
| **Scaled Content Abuse** | — | Google 针对大规模低质自动生成内容的惩罚政策 | SEO（风控） |
| **Helpful Content System** | — | Google 的"有用内容"算法更新，评估内容原创性与价值 | SEO（风控） |
| **FAQPage / HowTo** | — | Google Rich Results 结构化数据类型，已大幅收紧展现门槛 | SEO（风控） |
| **DPA** | Data Processing Agreement | 数据处理协议，GDPR 下与数据处理方签署的合同 | Operations（合规） |
| **VAT** | Value Added Tax | 增值税（欧盟） | Operations（税务） |
